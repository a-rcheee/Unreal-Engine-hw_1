## Unreal-Engine-hw_1

## Реализованный функционал:
1. **Базовый C++ класс:** Создан класс `ABaseCharacter`, от которого унаследован `BP_ThirdPersonCharacter`.
2. **Enhanced Input:** 
   - Созданы действия `IA_Sprint` и `IA_Interact`.
   - Настроена привязка в контексте `IMC_Default` (Left Shift и E).
   - Действия привязаны в C++ через `SetupPlayerInputComponent`.
3. **Делегаты и логика (C++ & Blueprints):**
   - Реализован `Dynamic Multicast Delegate`, вызываемый при нажатии клавиши **E**.
   - В `BP_ThirdPersonCharacter` оформлена подписка на делегат с выводом строки `"Interaction triggered!"` на экран.
   - Реализовано переключение скорости ходьбы и бега с записью в булеву переменную `IsSprinting`.
4. **Анимации (State Machine):**
   - Переменная `IsSprinting` считывается в Animation Blueprint.
   - В State Machine добавлено состояние `Sprint` с анимацией быстрого бега и настроены правила перехода в обе стороны.
5. **Механика выносливости:**
   - Реализована на C++ с расходом во время спринта и регенерацией в покое.
   - При истощении выносливости до 0 персонаж принудительно прекращает бег даже при удержании клавиши.
   - Текущее значение выносливости выводится на экран в реальном времени.

## Управление:
- **WASD** - Перемещение
- **Пробел** - Прыжок
- **Left Shift (зажатие)** - расходует выносливость
- **E** — Взаимодействие
